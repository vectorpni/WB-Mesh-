# Как подготовить ссылку на исходники

1. Распаковать **Mesh-Gate-source.zip** в чистую папку. Проверить README, выполнить `node --test` и запустить `node server.mjs`. Для «СТАРТ» в DOCX допускается архив или репозиторий. В расписании финала отдельно указана ссылка на код. Уточнить площадку и доступ жюри.
2. В новый репозиторий добавить только проверенные файлы архива. Проверить diff, список файлов и отсутствие токенов, ключей, персональных данных и исходного кейса. Артефакты XLSX и PDF прикладывать отдельно, если этого требует форма.
3. Локально можно выполнить `git init`, затем проверить `git status`, сделать коммит с текущей версией и записать SHA. Не заменять существующий репозиторий и его историю.
4. В разрешённой площадке создать приватный репозиторий или использовать разрешённый файловый канал. Открыть доступ жюри по правилам мероприятия. Публичная публикация только после разрешения владельца.
5. Проверить ссылку из другой сессии. Сдать **Final-Mesh-Gate.pdf** и рабочую ссылку на код до **14:45 МСК 26 ноября**, если не объявлено новое расписание. Сохранить подтверждение сдачи.
