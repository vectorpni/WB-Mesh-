# WB Mesh Control System

**Ближе товар. Сильнее сеть.**

Интеллектуальная система моделирования логистики между пунктами выдачи заказов (ПВЗ). Проект команды Vector PNI для хакатона RWB × ПГТУ «TOP AI START».

[Открыть демоверсию](https://vectorpni.github.io/WB-Mesh-/) · [Репозиторий](https://github.com/vectorpni/WB-Mesh-)

> Исследовательский MVP. Не является официальным сервисом Wildberries. Демонстрационные данные синтетические.

## Проблема и решение

Товар может находиться ближе к покупателю, чем предполагает классическая логистическая цепочка. WB Mesh исследует возможность использовать доступные остатки и существующую сеть ПВЗ, чтобы сокращать лишние перемещения, расходы и время доставки при соблюдении ограничений сети.

Система сравнивает допустимые варианты доставки, рассчитывает их экономику и объясняет выбранный маршрут. Если подходящего маршрута нет, система не должна выдавать фиктивный успешный результат.

## Как работает система

1. Формируется заказ с указанием товара и конечного ПВЗ.
2. Проверяются источники товара, доступные остатки, резервы и ограничения узлов.
3. Рассматриваются допустимые логистические цепочки.
4. MCS (Mesh Control System) сравнивает варианты по стоимости и ограничениям.
5. В демонстрационной среде моделируются операции заказа, перемещения и выдачи.
6. Экономический модуль показывает расходы и эффект относительно классической схемы.

### Модели логистики

| Модель | Принцип |
| --- | --- |
| M1 | Товар уже находится в конечном ПВЗ; автомобильный рейс не нужен. |
| M2 | Передача товара из другого допустимого Mesh-ПВЗ того же города. |
| C1 | Классическая городская логистическая цепочка. |
| C2 | Классическая междугородняя цепочка через хабы и магистраль. |

## Возможности V8

- Демонстрационная сеть ПВЗ и логистических узлов.
- Выбор маршрутов и объяснение решений MCS.
- Моделирование заказов, возвратов, резервирования и движения товара.
- Учёт остатков, вместимости и ограничений узлов.
- Прогнозирование спроса и планирование перемещений.
- Расчёт себестоимости, экономического эффекта и финансовых показателей.
- Демонстрационные сценарии городской и междугородней доставки, возврата, сбоя логистики и длительного хранения.

### Экономика

В контрольном примере проекта результат ПВЗ составляет 6,50 ₽: 14 ₽ дохода минус 7,50 ₽ расходов. Интерфейс V8 показывает расчётную экономию 7,04% для контрольного примера. Эти значения относятся к модельным условиям, а не к подтверждённым результатам реальной эксплуатации. Итог зависит от тарифов, объёмов, хранения и маршрута.

## Быстрый запуск

### Публичная демонстрация

Откройте [WB Mesh](https://vectorpni.github.io/WB-Mesh-/). Установка не требуется.

### Полная локальная сборка (Windows / PowerShell)

Для запуска серверной версии нужны Node.js и npm, а также полная ветка разработки с `package.json` и `server.js`.

```powershell
git clone --branch feature/codex-v8 https://github.com/vectorpni/WB-Mesh-.git
cd WB-Mesh-
npm ci
npm test
npm start
```

Откройте `http://localhost:3000/`.

Ветка `main` предназначена для статической публикации и не обязана содержать локальный сервер, тесты и зависимости.

## Ограничения

- Проект является демонстрационным MVP, а не действующей системой Wildberries.

- Первый локальный прототип V10 не является полной реализацией всех требований.
