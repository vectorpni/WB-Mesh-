# WB Mesh В· Vector PNI

Static browser demo of the current V8 prototype. Its data and financial scenarios are synthetic. This is a team project, not an official Wildberries service.

The site runs entirely in the browser. Session state is stored in localStorage. There is no shared database, login, payment processing or live logistics integration.

The project working tree, requirements, source documents, audits and V10 preparation remain in the local repository. This public branch contains only the website runtime files.
