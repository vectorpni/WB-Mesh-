Первый браузерный тест застрял на кириллическом селекторе, повреждённом преобразованием PowerShell. Перепроверка с устойчивым селектором прошла. При первом импорте таблицы LibreOffice мог использовать значения из кэша. Проверка через интерфейс Calc с calculateAll и редактированием готовой книги устранила эту неопределённость. При экспорте слайдов первый вариант потерял размеры шрифтов, следующий имел слишком маленький размер страницы. Финальный экспорт исправляет формат и проверен по рендеру.

Приложение не проверялось на реальных данных RWB, одновременной работе нескольких операторов или фактической нагрузке сети. Остаточные риски перечислены в [KILLCRITIC.md](KILLCRITIC.md).
