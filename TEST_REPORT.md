# Проверка WB Mesh V8

Дата: 26.11.2026. Проверки выполнялись на реальном локальном сервере, запущенном командой `npm run dev` на 127.0.0.1:3000.

## Ядро

`npm test`: **53 результата, 53 PASS, 0 FAIL**, включая пять сохранённых legacy тестовых файлов. Лог: `evidence/unit-tests.txt`. Проверены экономика, пороги, прогрессивное хранение, четыре стороны, маржа WB, отрицательные потоки NPV, маршруты, остатки, FIFO, резервирование, транзит, дубли, возвраты, осмотр и спрос, вывоз, импорт, сброс, восстановление, прогноз и попутные перемещения.

Воспроизведённые дефекты сначала подтверждались падающими регрессионными тестами. Mutation-проверка инвертировала `savings >= minimumSavings`: тест упал с exit1. Исходник восстановлен в finally; повторный тест прошёл. Это подтверждает чувствительность конкретной проверки, а не полное mutation coverage.
